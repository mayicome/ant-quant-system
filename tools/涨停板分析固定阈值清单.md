# 涨停板主力行为分析 - 固定阈值清单

## 一、诱多出货 (_analyze_limit_up_distribution)

### 封单量阈值
- **10000手**：买一量 > 10000手 且 成交量占比 < 10% → 判定为封死涨停板，返回0分
- **5000-10000手**：封单中等，且成交量占比 < 15%，且波动率 ≤ 0.20 → 返回0分

### 成交量占比阈值
- **0.1 (10%)**：成交量占买一量比例 < 10% → 判定为封死涨停板
- **0.15 (15%)**：成交量占买一量比例 < 15% → 中等封单检查

### 波动率阈值
- **0.20 (20%)**：波动率 ≤ 0.20 → 封单稳定，不是诱多出货

### 大单撤单判断
- **50000手**：初始封单 > 50000手
- **2倍**：初始封单 > 最后封单的2倍 → 判定为大单撤单

### 开合变化判断
- **3次**：开合变化次数 >= 3 → 判定为有开合行为

### 日K位置阈值
- **0.8 (80%)**：价格位置 > 80% → 高位，+20分

### 涨幅阈值
- **0.20 (20%)**：近3日累计涨幅 ≥ 20% → +10分

### 放量阈值
- **2倍**：当前成交量 ≥ 5日均量的2倍 → +20分

### 得分权重
- 大单撤单：+40分
- 开合变化：+30分
- 高位：+20分
- 涨幅≥20%：+10分
- 放量≥2倍：+20分

## 二、强势封板 (_analyze_limit_up_strong_seal)

### 封单量阈值（买一量）
- **10000手**：买一量 > 10000手 且 成交量占比 < 10% → 直接给高分
  - > 50000手 → 100分
  - > 20000手 → 90分
  - 其他 → 80分
- **5000-10000手**：中等封单，且成交量占比 < 15%
  - 波动率 ≤ 0.20 → +75分
  - 波动率 > 0.20 → +50分

### 成交量占比阈值
- **0.1 (10%)**：成交量占买一量比例 < 10% → 封死涨停板
- **0.15 (15%)**：成交量占买一量比例 < 15% → 中等封单检查

### 波动率阈值
- **0.20 (20%)**：波动率 ≤ 0.20 → 非常稳定，+40分
- **0.30 (30%)**：波动率 ≤ 0.30 → 较稳定，+20分；且按规模给分

### 封单规模阈值（总封单量）
- **30000手**：≥ 30000手 → +30分（需波动率 ≤ 0.30）
- **10000手**：≥ 10000手 → +25分（需波动率 ≤ 0.30）
- **5000手**：≥ 5000手 → +20分（需波动率 ≤ 0.30）

### 封板速度阈值
- **30分钟**：封板时间 ≤ 30分钟 → +30分

### 成交量萎缩阈值
- **0.30 (30%)**：封板后成交量 ≤ 封板前成交量的30% → +25分

### 日K位置阈值
- **0.15 (15%)**：价格位置 ≤ 15% → 低位，+20分
- **0.50 (50%)**：价格位置 ≤ 50% → 中位，+10分

### 得分权重
- 封死涨停板（>10000手，占比<10%）：
  - >50000手：100分
  - >20000手：90分
  - 其他：80分
- 稳定中等封单（5000-10000手，占比<15%，波动≤0.20）：+75分
- 封板速度≤30分钟：+30分
- 波动率≤0.20：+40分
- 波动率≤0.30：+20分
- 封单规模（需波动≤0.30）：
  - ≥30000手：+30分
  - ≥10000手：+25分
  - ≥5000手：+20分
- 成交量萎缩≤30%：+25分
- 低位（≤15%）：+20分
- 中位（≤50%）：+10分

## 三、洗盘 (_analyze_limit_up_wash)

### 开合周期要求
- **1个周期**：必须完成至少1个开合周期（封板→开板→封板）
  - 完成1个周期：+50分
  - 完成2个周期：+15分（额外）
  - 只有开板未回封：+20分
  - 无开板：最多30分

### 撤单稳定性阈值
- **0.20 (20%)**：波动率 ≤ 0.20 → 撤单少，+25分

### 成交量萎缩阈值
- **0.50 (50%)**：封板期间成交量 ≤ 封板前成交量的50% → +25分

### 日K横盘阈值
- **0.03 (3%)**：近5日振幅 ≤ 3% → +20分

### 得分权重
- 完成1个开合周期：+50分
- 完成2个开合周期：+15分（额外）
- 只有开板未回封：+20分
- 撤单少（波动≤0.20）：+25分
- 成交量萎缩≤50%：+25分
- 日K横盘（振幅≤3%）：+20分

## 四、试盘 (_analyze_limit_up_test)

### 封单量阈值
- **10000手**：平均封单量 ≤ 10000手 → +50分
- **20000手**：平均封单量 ≤ 20000手 → +25分（且波动大才是试盘特征）

### 波动率阈值
- **0.40 (40%)**：波动率 ≥ 0.40 → +40分（需封单≤20000手）
- **0.30 (30%)**：波动率 ≥ 0.30 → +20分（需封单≤20000手）

### 尾盘封板阈值
- **30分钟**：封板时间在最后30分钟内 → +25分

### 成交量阈值
- **0.80 (80%)**：封板期间平均成交量 ≤ 封板前平均成交量的80% → +15分

### 日K震荡阈值
- **0.02 (2%)**：近5日价格波动 < 当前价格的2% → +20分

### 得分权重
- 封单量≤10000手：+50分
- 封单量≤20000手：+25分
- 波动率≥0.40（需封单≤20000手）：+40分
- 波动率≥0.30（需封单≤20000手）：+20分
- 尾盘封板（最后30分钟）：+25分
- 成交量≤80%：+15分
- 日K震荡（波动<2%）：+20分

## 五、数据量要求

### 最小数据量
- **10条**：limit_up_data 需要至少10条数据才能进行稳定性分析
- **5条**：limit_up_data 需要至少5条数据才能进行成交量分析
- **60天**：日线数据需要至少60天才能进行位置分析
- **3天**：日线数据需要至少3天才能进行涨幅分析
- **5天**：日线数据需要至少5天才能进行横盘/震荡分析

## 总结

### 封单量相关阈值
- 10000手：大封单阈值
- 5000手：小封单阈值
- 20000手：中等封单阈值
- 30000手：超大封单阈值
- 50000手：超大封单阈值（诱多出货大单撤单判断）

### 比例/百分比阈值
- 0.1 (10%)：成交量占比（封死涨停板）
- 0.15 (15%)：成交量占比（中等封单）、价格位置（低位）
- 0.20 (20%)：波动率（稳定）、价格位置（高位判断）
- 0.30 (30%)：波动率（较稳定）、成交量萎缩
- 0.40 (40%)：波动率（试盘特征）
- 0.50 (50%)：价格位置（中位）、成交量萎缩（洗盘）
- 0.80 (80%)：价格位置（高位）、成交量（试盘）

### 时间阈值
- 30分钟：封板速度、尾盘封板判断

### 倍数阈值
- 2倍：大单撤单判断、放量判断

### 次数阈值
- 3次：开合变化次数
- 1个周期：洗盘开合周期（最低要求）
- 2个周期：洗盘开合周期（多次开合）
