## 关键问题识别

### 核心问题：诱多出货被过度识别

**误判模式：**
- **强势封板 → 诱多出货**: 7/11 = 63.6%
- **洗盘 → 诱多出货**: 3/4 = 75%
- **试盘 → 诱多出货**: 1/5 = 20%

**结论：** 诱多出货的得分可能普遍偏高，导致其他行为被误判为诱多出货。

```

### 策略1：降低诱多出货的得分（关键）

**问题根源：** 诱多出货得分过高，导致强势封板和洗盘被误判

**解决方案：**
```

- distribution_bias: 0 ~ 5 (步长1.0)  ← 从9.0降低到0-5

或者降低诱多出货的权重：
- distribution_weight: 0.7 ~ 1.0 (步长0.1)  ← 从1.0降低到0.7-1.0
```

### 策略2：提高强势封板和洗盘的得分

**同时进行：**
```
提高强势封板偏移量：
- strong_seal_bias: -5 ~ 5 (步长2.5)  ← 从-11.0提高到-5~5

提高洗盘偏移量：
- wash_bias: -5 ~ 5 (步长2.5)  ← 从-13.0提高到-5~5

提高洗盘权重：
- wash_weight: 0.5 ~ 0.8 (步长0.1)  ← 从0.3提高到0.5-0.8
```

### 策略3：组合优化（推荐）

**同时降低诱多出货，提高强势封板和洗盘：**

```

- distribution_weight: 0.7 ~ 1.0 (步长0.1)  ← 从1.0降低

- strong_seal_bias: -5 ~ 5 (步长2.5)  ← 从-11.0提高

- wash_bias: -5 ~ 5 (步长2.5)  ← 从-13.0提高
