# 混淆矩阵分析结果与优化建议

## 当前问题分析

### 混淆矩阵结果：
- **强势封板**: 54.5% 准确率 (6/11) - 4个被误判为洗盘，1个被误判为诱多出货
- **试盘**: 0% 准确率 (0/5) - **全部被误判为洗盘**
- **洗盘**: 75% 准确率 (3/4) - 1个被误判为强势封板
- **诱多出货**: 0% 准确率 (0/3) - **全部被误判为洗盘**

### 核心问题：
1. **洗盘被过度识别**：试盘、诱多出货、部分强势封板都被误判为洗盘
2. **试盘和诱多出货完全无法识别**：得分可能普遍偏低

## 优化建议

### 方案1：调整权重参数（推荐先试这个）

**降低洗盘权重，提高试盘和诱多出货权重：**

```
参数范围调整建议：
- wash_weight: 0.3 ~ 1.0 (降低洗盘权重，步长0.1)
- test_weight: 1.5 ~ 3.0 (提高试盘权重，步长0.2)
- distribution_weight: 1.5 ~ 3.0 (提高诱多出货权重，步长0.2)
- strong_seal_weight: 0.8 ~ 1.5 (微调，步长0.1)
```

### 方案2：使用偏移量参数

**给试盘和诱多出货加分，给洗盘减分：**

```
偏移量参数调整建议：
- wash_bias: -30 ~ -10 (给洗盘减分，步长5)
- test_bias: 10 ~ 30 (给试盘加分，步长5)
- distribution_bias: 10 ~ 30 (给诱多出货加分，步长5)
- strong_seal_bias: -10 ~ 10 (微调，步长5)
```

### 方案3：组合优化（权重 + 偏移量）

**同时调整权重和偏移量：**

```
权重参数：
- wash_weight: 0.5 ~ 1.0
- test_weight: 1.5 ~ 2.5
- distribution_weight: 1.5 ~ 2.5
- strong_seal_weight: 1.0 ~ 1.5

偏移量参数：
- wash_bias: -20 ~ 0
- test_bias: 0 ~ 20
- distribution_bias: 0 ~ 20
- strong_seal_bias: -10 ~ 10
```

### 方案4：启用最小得分差异阈值

**避免得分接近时的误判：**

- 启用"最小得分差异阈值"，设置为 5-15
- 这样只有当最高分明显高于次高分时，才确定主导行为
- 如果得分差异不够，会使用优先级规则（强势封板 > 诱多出货 > 试盘 > 洗盘）

### 方案5：启用得分归一化

**平衡不同行为的得分范围：**

- 勾选"得分归一化"选项
- 这会将所有行为的得分归一化到0-100范围
- 有助于平衡不同行为的得分范围差异

## 推荐优化步骤

1. **第一步**：先尝试方案1（调整权重），重点关注：
   - 降低 `wash_weight` 到 0.3-0.8
   - 提高 `test_weight` 到 1.5-2.5
   - 提高 `distribution_weight` 到 1.5-2.5

2. **第二步**：如果权重调整效果不理想，尝试方案2（偏移量）：
   - 给洗盘减分（-20 到 -10）
   - 给试盘和诱多出货加分（10 到 20）

3. **第三步**：如果前两步效果仍不理想，尝试方案3（组合优化）

4. **第四步**：启用最小得分差异阈值（5-15）和归一化选项

## 预期目标

- **试盘识别准确率**: 从 0% 提升到至少 40%
- **诱多出货识别准确率**: 从 0% 提升到至少 40%
- **整体准确率**: 从 26% 提升到至少 40%
