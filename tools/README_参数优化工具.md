# 涨停板主力行为分析 - 参数优化工具

## 功能说明

这个工具可以自动搜索最优参数组合，提高涨停板主力行为识别的准确率。

## 使用方法

### 1. 准备数据文件

创建一个文本文件，格式为：`主力行为\t股票代码\t日期`

示例：
```
强势封板	000555	2025-10-30
强势封板	000555	2025-11-03
洗盘	002386	2025-10-30
试盘	002693	2025-10-30
诱多出货	603021	2025-10-30
```

### 2. 运行程序

```bash
python tools/limit_up_parameter_optimizer_gui.py
```

### 3. 操作步骤

1. **加载数据文件**：点击"加载数据文件"按钮，选择准备好的数据文件
2. **设置参数范围**：在参数表格中设置要优化的参数范围
   - 参数名：要优化的参数名称
   - 最小值：参数的最小值
   - 最大值：参数的最大值
   - 步长：参数搜索的步长
3. **设置最大迭代次数**：如果参数组合数过多，会使用随机搜索，限制最大迭代次数
4. **开始优化**：点击"开始优化"按钮，程序会自动搜索最优参数
5. **查看结果**：优化完成后，在"最优参数结果"区域查看最优参数和准确率

## 当前支持的参数

目前支持通过权重调整来优化识别准确率：

- `strong_seal_weight`: 强势封板权重（默认1.0）
- `test_weight`: 试盘权重（默认1.0）
- `wash_weight`: 洗盘权重（默认1.0）
- `distribution_weight`: 诱多出货权重（默认1.0）

## 注意事项

1. **避免过拟合**：建议使用足够多的样本数据，避免参数过度拟合到训练集
2. **匹配率目标**：工具设计目标是匹配率>30%，不追求100%匹配
3. **数据质量**：确保输入的数据文件格式正确，股票代码和日期有效
4. **运行时间**：参数优化可能需要较长时间，请耐心等待

## 后续扩展

如果需要更深入的参数优化（如阈值参数、得分权重等），可以扩展`ParameterizedAnalyzer`类，实现更细粒度的参数控制。
