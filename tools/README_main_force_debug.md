# 主力行为分析调试工具使用说明

## 功能说明

这个工具用于批量分析一组股票在某个时间段的所有主力行为的详细得分，包括：
- **高位出货**：总分 + 3个公式得分
- **低位吸筹**：总分 + 3个公式得分
- **主力拉升**：总分 + 3个公式得分
- **主力洗盘**：总分 + 3个公式得分
- **主力扫货**：总分 + 3个公式得分

所有结果会导出到Excel文件，方便进行数据分析和验证。

## 使用方法

### 命令行参数

```bash
python tools/main_force_analysis_debug.py \
    --stocks "000001.SZ,600000.SH,000002.SZ" \
    --start-date "2024-11-01" \
    --end-date "2024-11-05" \
    --output "main_force_analysis.xlsx"
```

### 参数说明

- `--stocks`: 股票代码列表，用逗号分隔。支持格式：
  - `000001.SZ` (完整格式)
  - `000001` (自动识别市场)
- `--start-date`: 开始日期，格式：`YYYY-MM-DD`
- `--end-date`: 结束日期，格式：`YYYY-MM-DD`
- `--output`: 输出Excel文件名（可选，默认：`main_force_analysis.xlsx`）

### 示例

#### 示例1：分析单只股票多日数据
```bash
python tools/main_force_analysis_debug.py \
    --stocks "000001.SZ" \
    --start-date "2024-11-01" \
    --end-date "2024-11-05" \
    --output "000001_analysis.xlsx"
```

#### 示例2：分析多只股票单日数据
```bash
python tools/main_force_analysis_debug.py \
    --stocks "000001.SZ,600000.SH,000002.SZ" \
    --start-date "2024-11-05" \
    --end-date "2024-11-05" \
    --output "multi_stocks_20241105.xlsx"
```

#### 示例3：分析多只股票多日数据
```bash
python tools/main_force_analysis_debug.py \
    --stocks "000001.SZ,600000.SH" \
    --start-date "2024-11-01" \
    --end-date "2024-11-10" \
    --output "batch_analysis.xlsx"
```

## 注意事项

1. **数据获取**：工具需要QMT连接来获取历史tick数据和日线数据，确保QMT已启动并连接成功。

2. **交易日过滤**：工具会自动过滤非交易日，只分析交易日的数据。

3. **数据缺失**：如果某只股票在某个日期没有tick数据或日线数据，会在状态列标记，并在错误信息中说明。

4. **分析时间**：批量分析可能需要较长时间，特别是分析多只股票多日数据时。建议先用少量数据测试。

5. **Excel文件**：如果输出文件已存在，会被覆盖。

## 调试建议

1. **验证准确性**：
   - 对比分析结果与实际价格走势
   - 统计各行为类型的得分分布
   - 找出高分但后续走势不符合预期的案例

2. **参数优化**：
   - 分析不同得分区间的准确率
   - 找出关键公式（哪个formula对准确率影响最大）
   - 调整权重分配

3. **数据质量**：
   - 检查数据缺失情况
   - 验证tick数据的完整性
   - 确认日线数据的准确性

## 常见问题

**Q: 提示"无tick数据"？**
A: 可能是该日期没有交易，或者QMT数据源中没有该日期的数据。检查日期是否为交易日，以及QMT是否已下载该日期的历史数据。

**Q: 提示"无日线数据"？**
A: 可能是股票代码格式错误，或者QMT数据源中没有该股票的数据。检查股票代码是否正确。

**Q: 分析速度很慢？**
A: 这是正常的，因为需要获取历史数据并执行复杂的分析计算。建议先用少量数据测试，或者分批分析。
