# 技术反转策略规格 v1.0（短线 · 技术因子 · 暴露×溢价框架）

> 依据《Quantitative Equity Portfolio Management》（Chincarini & Kim）的线性因子模型与 Fama-MacBeth 两阶段估计方法设计。
> 状态：**设计已收敛，可作实现合同**；未接入数据、未写回测代码。
> 前身：趋势策略规格 v1.2（动量方向）经 full_run2 / half_run1 两轮回测证实 A 股短周期上趋势动量框架失效，全部因子 IC 为负、仅 BRK10 溢价为正；本规格在同一工程底座上将因子暴露反转为反转方向，保留 FM 横截面溢价估计与全部交易约束。

---

## 0. 策略定位

| 项 | 内容 |
|---|---|
| 策略类型 | 技术反转（超跌反弹），纯做多 |
| 理论框架 | 收益 = 因子暴露 × 因子溢价；每期横截面回归估计溢价 |
| 因子范围 | 仅技术因子（不考虑基本面因子、市场因子） |
| 暴露口径 | 当期可观测技术因子值（标准化后）充当暴露；**除 BRK10 外全部取负**，将"趋势强"翻转为"超跌"暴露 |
| 信号频率 | **因子日频计算**；**调仓与 FM 观测为周频**（先回到周频，确认信号有效性后再评估提频） |
| 默认市场 | A 股全市场（沪深主板 + 创业板 + 科创板，剔除北交所），含 T+1、涨跌停、成本约束 |
| 与 hold3 反转的关系 | hold3_round 系列基于价格偏离/超跌度量的 FM 打分；本规格基于**技术指标（动量/斜率/量价/均线/突破）**的 FM 反转，因子来源不同，可互为对照与补充 |

### 0.1 改版动机（设计依据）

1. **趋势动量在 A 股短周期失效**：full_run2（周频）与 half_run1（3 交易日调仓+短周期因子）均亏损，half_run1 总收益 −39.4%、年化 −7.5%、MaxDD −48.4%、Sharpe −0.21。
2. **信号本质是反转，不是趋势**：half_run1 中 MOM10 / SLOPE30 / VPC3 / MAALG 的 IC 全部为负，溢价也为负——"趋势强"的股票后续更易下跌，"趋势弱/超跌"的股票后续更易反弹。
3. **BRK10 是唯一正向信号**：half_run1 中仅 BRK10 溢价显著为正，向上突破仍有短期延续性，因此保留正向、不取负。
4. **半周调仓不可行**：half_run1 换手中位数顶满 45% 上限，成本与递延成交吞噬 alpha；先回到周频确认信号本身，再评估是否提频。
5. **因子窗口适配短周期反转**：MOM10 / SLOPE30 / VPC3 / 短均线组（MA3-MA6-MA12），比 v1.2 的 MOM20 / SLOPE60 / VPC5 更短，捕捉 1~4 周级别的超跌反弹。

## 1. 市场范围与候选池过滤

**候选池**：全市场 = 沪深主板 + 创业板 + 科创板（**剔除北交所**）。

选全市场而非指数成分的理由（继承 v1.2）：
1. **横截面回归需要大样本**——全市场 4000~5000 只 vs 沪深300 的 300 只，溢价估计稳定性依赖样本量；
2. **反转效应在中小盘更强**——大盘蓝筹机构定价充分、超跌反弹空间有限；中小盘波动大、超跌后反弹弹性更高；
3. **流动性用过滤解决，不靠换池子**——保住样本的同时控制可交易性。

**候选池硬过滤（逐期执行，用时点快照防幸存者偏差）：**

| 过滤项 | 规则 | 原因 |
|---|---|---|
| ST/*ST | 剔除（按**当时名称/状态**时点判断） | 退市风险 + 涨跌幅规则不同 |
| 次新股 | 上市不足 120 个交易日剔除 | 因子数据不足 + 波动异常 |
| 流动性 | 过去 20 个交易日日均成交额 > 1 亿（参数可调；**含当日**） | 短线可交易性 |
| 停牌 | 剔除（无官方停牌日历时：成交额/量为 0 且价格不变等启发式） | 无法交易 |
| 涨跌停 | **非事前过滤**；组合构建/成交时用不复权价判断一字板不可成交 | 见 §6 |

**数据字段清单（日频）：**

必需：
- **后复权收盘价**（因子计算、FM 左侧收益）
- **日成交额**（VPC3；库内单位按元，阈值 1 亿 = `1e8`）
- **不复权开盘价 / 收盘价**（成交执行、涨跌停判断）
- **上市日期**（次新过滤）

建议补充：
- 复权因子 / 除权除息记录（可选；方案 A 下账本不依赖复权因子）
- 涨跌停标记、停牌标记、时点上市/退市快照

不需要：最高/最低价（BRK10 用过去最高**收盘价**）。

覆盖长度：至少 4 年（估计窗口 52 周 + 样本外）。

## 2. 因子体系（5 因子 + 1 质量过滤）

所有因子在 **t 日收盘后**计算，严格无前视偏差。
周调仓日使用**当日收盘后**算出的因子截面做排序与当期横截面回归。

### 2.1 因子定义

| # | 因子 | 公式（t 日口径） | 原始方向 | **暴露方向（输入 FM）** | 暴露算法 |
|---|---|---|---|---|---|
| 1 | MOM10 短期动量 | `(P(t-1) / P(t-11)) − 1`，剔除最近 1 日 | + | **−MOM10**（取负） | winsorize → 截面 z-score |
| 2 | SLOPE30 趋势斜率 | 30 日 `ln(P)` 对时间序号 OLS 斜率 `b × 252` | + | **−SLOPE30**（取负） | 同上 |
| 3 | BRK10 突破强度 | `(P(t) − H10) / H10`，`H10 = max(P[t-10 … t-1])`（**不含当日**） | + | **BRK10（保留正向）** | 同上 |
| 4 | VPC3 量价配合 | `R3 × (Vol3 / Vol10)`，成交额口径；`R3` = 近 3 日收益，`Vol3`/`Vol10` = 近 3/10 日成交额均值 | + | **−VPC3**（取负） | 同上 |
| 5 | MAALG 短均线排列 | `(MA3 − MA6)/MA6 + (MA6 − MA12)/MA12` | + | **−MAALG**（取负） | 同上 |

价格 `P` 一律为**后复权收盘价**。窗口按**交易日**计数；中间停牌导致的缺口：该票在因子所需最短历史上不足则剔除出当期池。

### 2.2 暴露取负的含义

取负后，输入 FM 的暴露含义变为：

| 取负后暴露高 | 对应原始状态 | 反转预期 |
|---|---|---|
| −MOM10 高 | 过去 10 日**大跌** | 超跌反弹，预期收益高 |
| −SLOPE30 高 | 过去 30 日价格**下行斜率大** | 超跌反弹，预期收益高 |
| BRK10 高（未取负） | 向上突破 10 日高点 | 短期延续，预期收益高 |
| −VPC3 高 | 近 3 日**价跌量缩**（或价跌量不配合） | 抛压衰竭，预期收益高 |
| −MAALG 高 | 短均线**空头排列**（MA3<MA6<MA12） | 超跌反弹，预期收益高 |

组合本质：**优先选短期超跌（动量/斜率/量价/均线均指向弱势），同时不排除向上突破的标的**——是"反转为主 + 少量突破"的混合策略。

### 2.3 设计要点

- MOM10 剔除最近 1 日，减轻与日内噪声混杂；10 日窗口适配 1~3 周级反转。
- SLOPE30 用对数价格回归，横截面更可比；30 日窗口比 v1.2 的 60 日更短，捕捉中期下行后的反弹。
- BRK10 **唯一保留正向**：half_run1 实证其溢价显著为正，向上突破在 A 股短周期仍有延续性，不随其他因子取负。
- VPC3 用成交额而非股数，规避股本变动；3 日窗口比 v1.2 的 5 日更短。
- MAALG 改用短均线组（MA3-MA6-MA12），替代 v1.2 的 MA5-MA10-MA20，适配短周期反转。
- 标准化顺序：**先 R² 质量过滤（§3）→ 再对保留样本 winsorize（1%/99%）→ 再截面 z-score → 最后对 MOM10/SLOPE30/VPC3/MAALG 取负**（BRK10 不取负）。

## 3. R² 质量过滤（硬门槛）

- **位置**：因子计算之后、标准化之前。
- **规则**：SLOPE30 回归的拟合优度 R² 低于阈值 → 该票当期出局（不参与标准化、不参与溢价回归、不进入候选排序）。
- **默认阈值**：全市场 R² 中位数作起点；回测扫描 `0.25 / 0.30 / 0.35 / 0.40`。
- **阈值下调理由**：SLOPE 窗口从 60 日缩短到 30 日，价格噪声占比上升，全市场 R² 分布整体下移；沿用 v1.2 的 0.4~0.7 会过滤掉过多样本。
- **反转场景下 R² 的含义**：R² 高代表过去 30 日价格趋势清晰（持续上涨或持续下跌）；反转策略中，持续下跌且 R² 高的标的是"确定性超跌"，是理想候选；因此 R² 过滤只剔除"趋势不清晰/噪声大"的标的，不剔除高 R² 标的。
- **联动**：过滤后样本过小（如 < 800 只）时放宽阈值，保证溢价回归样本量。

## 4. 因子溢价估计（Fama-MacBeth 两阶段）

### 4.1 时间轴（周频）

| 概念 | 定义 |
|---|---|
| 周边界 | 自然周；调仓观测日 = **该周最后一个交易日**（周五休市则用当周末日） |
| 记 `T` | 第 `T` 个周调仓观测日（收盘后） |
| 因子 / 暴露 | 每日可算；决策只用 `T` 日收盘后因子（含取负后的暴露） |
| 执行 | **`T` 的下一交易日开盘**（不复权开盘价） |
| FM 左侧收益 | 后复权周收益（见下） |

### 4.2 左侧收益（研究 / 回归用）

```
r(i, T+1) = P_hfq(T+1) / P_hfq(T) − 1
```

- `P_hfq`：后复权收盘价。
- 周频：`T+1` / `T` 均为各自周的**最后一个交易日收盘**（「周五收 / 上周五收」口径，遇休市用当周末日）。
- **每期横截面对 `r` 做 winsorize 1%/99%** 后再回归（防除权异常、坏数据、复牌跳空污染）。

### 4.3 第一步 —— 每期横截面回归

```
r(i, T+1) = α(T) + Σ_k β(i,k,T) · f(k,T) + ε(i,T)
```

- `β(i,k,T)`：股票 i 在 `T` 日的**取负后**标准化因子暴露（已知）。即 β_MOM10 = −z(MOM10)，β_SLOPE30 = −z(SLOPE30)，β_BRK10 = z(BRK10)，β_VPC3 = −z(VPC3)，β_MAALG = −z(MAALG)。
- `f(k,T)`：因子 k 在 `T` 期的溢价（待估）。
- 回归样本 = 通过 R² 过滤且通过硬过滤的可交易池。

### 4.4 第二步 —— 滚动溢价与预测

- 估计窗口 **W = 52**（单位 = **周调仓期数**，非日历日）。
- 在 `T` 日做预测时，仅使用**已实现**的历史溢价 `{f(k, T-W) … f(k, T-1)}`（严格无前视；不含当期未实现的 `f(k,T)`，因 `r(T+1)` 尚未发生）。
- `f̄(k,T) = mean( f(k, τ) )`，τ ∈ [T−W, T−1]。
- `ᾱ(T)` 同理滚动；**选股排序可丢掉截距**，只用 `Σ_k β(i,k,T) · f̄(k,T)`（默认丢掉 α，保持横截面可比）。
- 预测：`E[r(i,T+1)] = Σ_k β(i,k,T) · f̄(k,T)`，降序取前 N。

显著性报告（研究用）：

```
f̄(k) = mean_τ f(k,τ)
t(k)  = f̄(k) / (σ(k) / √T_obs)   ← 用 Newey-West 修正
```

### 4.5 预期溢价方向（设计自检）

取负后，我们预期各因子溢价 `f̄(k)` 为**正**：

| 因子（取负后暴露） | 预期溢价方向 | 含义 |
|---|---|---|
| −MOM10 | 正 | 超跌暴露越高，预期收益越高 |
| −SLOPE30 | 正 | 下行斜率越大（超跌越确定），预期收益越高 |
| BRK10 | 正 | 向上突破越强，预期收益越高（half_run1 已验证） |
| −VPC3 | 正 | 价跌量缩（抛压衰竭）暴露越高，预期收益越高 |
| −MAALG | 正 | 空头排列越极端，预期收益越高 |

**若回测中多数因子溢价仍为负或接近 0**，说明 FM 横截面框架对这组技术反转因子不适用，触发降级方案（见 §10）。

## 6. 组合构建与交易

### 6.1 基本规则

| 项 | 规则 |
|---|---|
| 选股 | `E[r]` 降序取前 **N = 20** |
| 权重 | **等权**；验证通过前不做暴露加权 |
| 行业/市值中性 | 先不做（r1 基线；r2 可叠加行业帽等约束，参考 hold3_round3 经验） |
| 止损/止盈 | 先不做；纯再平衡 |
| 单期换手上限 | **30%**（按卖出/替换金额占 NAV；**闲置现金建仓不计入换手帽**，否则空仓无法加满） |
| 成本 | 双边 **0.15%** 起点（佣金+印花税+滑点打包；实现时可拆：印花税仅卖出） |
| 基准 | 中证全指（000985），仅作超额对比 |
| 执行 | 调仓观测日 `T` 收盘决策 → **下一交易日开盘**成交 |

### 6.2 价口径分离（方案 A，继承 v1.2）

| 用途 | 价格口径 |
|---|---|
| 因子、FM 左侧 `r`、IC / 分组研究 | **后复权收盘** |
| 买入/卖出成交、涨跌停/一字板判断 | **不复权**开盘/收盘 |
| 组合账本（持仓、现金、NAV、换手、成本） | **全程不复权**：开盘成交 + 不复权收盘盯市 |

研究序列与交易账本分离，**不做**成交价 ↔ 后复权空间的映射。

### 6.3 买不进（涨停一字板，不复权判断）

1. 当期买入失败 → **该目标槽位现金滞留**（如实计 0 收益），订单标记 `"递延买入"`。
2. **不把失败权重重摊到其他已持/待买股票**（避免隐形加仓）。
3. **下一调仓日优先处理**：若该股票**仍在当期目标组合**，按当日开盘价再试买入。
4. 若已不在目标组合 → **自动放弃**，不追买。
5. **最多顺延 1 个周调仓期**；连续两个调仓日都买不进 → 强制放弃。

### 6.4 卖不出（跌停一字板，不复权判断）

1. 当期卖出失败 → **继续持有**，后续盈亏如实计入组合，标记 `"递延卖出"`。
2. 下一调仓日**优先开盘卖出**；仍跌停则再顺延。
3. **最多作为「优先卖出」顺延 1 期**；顺延期间占用的权重是组合真实偏离，**不得偷偷调平**。
4. 若下一期该股**仍在目标持仓** → **取消递延卖出**，恢复正常持有。
5. 优先顺延期满仍卖不出 → **继续持有直到可卖**（回测如实记录），不再享受优先队列以外的特殊待遇。

### 6.5 T+1

A 股 T+1：当日买入不得当日卖出；再平衡引擎须遵守（含递延成交后的可卖日）。

## 7. 参数表（v1.0 默认）

| 参数 | 默认 | 备注 |
|---|---|---|
| 市场 / 标的池 | 全市场（主板+创业板+科创板，剔北交所） | 已定 |
| 流动性阈值 | 20 日日均成交额 > 1 亿 | 资金规模大时可上调 |
| 次新剔除 | 上市不足 120 个交易日 | 已定 |
| 因子计算 | 日频 | 已定 |
| 调仓 / FM 周期 | 周频（周最后一个交易日决策） | 先回周频；确认信号后再评估提频 |

## 8. 实验组设计（r1 跑批矩阵）

底座：周频调仓，N=20，W=52，候选池不变，成本双边 0.15%。

### 8.1 实验组 A：混合反转 + 突破（主实验）

- 因子暴露：−MOM10 / −SLOPE30 / **BRK10（正向）** / −VPC3 / −MAALG
- 目标：短期超跌为主，同时保留 BRK 向上突破信号，不把突破信息丢掉。
- 这是本规格的**默认实验组**。

### 8.2 实验组 B：纯反转（全部取负）

- 因子暴露：−MOM10 / −SLOPE30 / **−BRK10** / −VPC3 / −MAALG
- 目标：彻底不要突破信号，纯押注超跌反弹；与 A 做对照，看 BRK10 是否提供增量。
- 若 B 显著差于 A，证明 BRK10 正向保留有价值；若 A/B 接近，说明 BRK10 贡献有限。

### 8.3 参数扫描网格

| 参数 | 扫描值 | 说明 |
|---|---|---|
| R² 阈值 | 0.25 / 0.30 / 0.35 / 0.40 | SLOPE30 质量过滤 |
| 持仓数 N | 18 / 20 / 22 | 信号集中度 vs 分散度 |
| 实验组 | A（混合）/ B（纯反转） | BRK10 方向对照 |

合计 4 × 3 × 2 = **24 组回测**。

### 8.4 输出指标清单

每组回测必须输出：
- 年化收益、总收益、年化波动、Sharpe、MaxDD、Calmar
- 年化换手（中位数 + 均值）、递延买入占比、递延卖出占比、卖出失败率
- 各因子 IC 均值 / ICIR / t 值（取负后方向）
- 10 分组收益、多空价差（D10−D1）
- FM 每期横截面回归平均 R²
- 各因子滚动溢价时序均值与 Newey-West t 值

汇总路径：`history_data/reversion_strategy/tech_rev_fm/r1_summary.csv`

## 10. 降级方案（若 FM 反转框架仍失效）

### 10.1 触发条件

若 r1 回测出现以下任一现象，判定 FM 横截面框架对这组技术反转因子不适用：
1. 取负后多数因子 IC 仍接近 0 或为负（预期应为正）；
2. 10 分组无单调性，多空价差不显著；
3. FM 每期横截面 R² 持续 < 1%；
4. 组合年化收益 < 0 或 Sharpe < 0。

### 10.2 降级路径

**降级 1：抛弃 FM 溢价估计，退回到简单打分范式**
- 用 ICIR 加权（或等权）对 5 个取负后因子做合成打分：
  ```
  score(i) = Σ_k w(k) · β(i,k)，w(k) = ICIR(k) / Σ|ICIR|
  ```
- 不再做横截面回归与滚动溢价估计，直接按 score 降序取前 N。
- 这与 hold3_round 系列的打分范式一致，只是因子池换成技术反转因子。
- 可直接复用 hold3_round 的打分引擎与交易引擎。

**降级 2：若简单打分仍无效，判定该组技术因子在 A 股无稳定 alpha**
- 停止在技术因子方向继续迭代；
- 归档当前最优版本（无论是否达标）；
- 转向其他因子来源（基本面 / 量价微观结构 / 事件驱动），或回到 hold3 反转框架继续优化。

## 11. 后续迭代方向（r2 及以后，仅作规划，非 r1 约束）

r1 确认信号有效后，r2 可参考 hold3_round3 的成功经验叠加约束：

| 方向 | 参考参数 | 预期效果 |
|---|---|---|
| 行业帽约束 | `industry_cap_k = 4`（单行业持仓不超过 4 只） | 降低行业集中风险，hold3 中 A_IND_CAP4 年化 +13.1% |
| 流动性过滤 | `liquidity_pct = 0.05`（20 日日均成交额 > 0.5 亿） | hold3 中 LQ05 单独使用年化降幅 ≤ 3pp |
| 波动过滤 | `vol_filter = ATR10`（剔除 ATR 顶部 10%） | hold3 中 CAP4+LQ05+ATR10 组合回撤从 −35% 压到 −26% |
| 大盘状态过滤 | 条件仓位（不利环境 N=20→8~12），而非直接空仓 | 避免全盘关闭吃掉反转 alpha |

**不建议**在 r1 阶段就叠加以上约束——先确认因子信号本身是否有效，再做组合层优化。
