# 蚂蚁量化 · 智能体数据包说明

面向连接器日更与离线试用包（`ant-quant-data.zip`）。  
格式统一为 **UTF-8 JSONL**：一行一条 JSON 对象；另有少量 `*_export_meta.json` 记录导出元信息。

**Agent Skill（AgentSkills 通用）**：仓库 / 离线包内 `skills/ant-quant-data/`（含 `SKILL.md`）。WorkBuddy 请**指定该目录**安装；适用于 Cursor / OpenClaw龙虾 / WorkBuddy / Hermes。

公共字段（多数行情类文件都有）：

| 字段 | 含义 | 示例 |
|---|---|---|
| `trade_date` | 交易日 | `2026-08-28` |
| `trade_date_ymd` | 交易日紧凑格式 | `20260828` |

---

## 1. 目录结构

```
cos/   （离线 zip 解压后根目录；COS 上为桶内 cos/ 前缀）
├── README.md                          ← 本说明
├── skills/ant-quant-data/             ← 指定此目录安装（内含 SKILL.md）
├── after_hours/
│   ├── after_hours_top.jsonl          ← 盘后量 Top 合并（全历史一小文件）
│   └── after_hours_top_export_meta.json
├── board_rank/
│   ├── {YYYYMMDD}.board_industry.jsonl
│   ├── {YYYYMMDD}.board_concept.jsonl
│   └── board_rank_export_meta.json
├── lhb/
│   ├── lhb_base_main.jsonl            ← 历史合并 · 主力情报
│   ├── lhb_base_total.jsonl           ← 历史合并 · 总榜
│   ├── lhb_base_seat.jsonl            ← 历史合并 · 席位明细
│   ├── {YYYYMMDD}.lhb_main.jsonl      ← 当日分片（日更追加）
│   ├── {YYYYMMDD}.lhb_total.jsonl
│   ├── {YYYYMMDD}.lhb_seat.jsonl
│   └── lhb_base_export_meta.json
├── main_flow/
│   ├── {YYYYMMDD}.main_flow.jsonl     ← 全市场主力净流入日分片
│   └── main_flow_export_meta.json
└── stock_info/
    ├── all_a_stock_info.jsonl         ← 全 A 股票信息（最新全量覆盖）
    ├── all_a_stock_info.snapshot.json ← 导出用快照（对比增量）
    ├── {YYYYMMDD}.stock_info_delta.jsonl  ← 有变更时才生成
    └── stock_info_export_meta.json
```

**日更习惯**：`board_rank` / `main_flow` / `lhb` 当日分片按天新增或覆盖；`after_hours_top.jsonl`、`all_a_stock_info.jsonl`、`lhb_base_*.jsonl` 为合并/全量文件，整文件覆盖。

## 2. 盘后量 · `after_hours/`

| 项 | 说明 |
|---|---|
| 文件 | `after_hours_top.jsonl`（单文件合并，约数百行/天累计） |
| 来源 | 每日盘后量 Top 选股结果 |
| 粒度 | 一行 = 某日入选的一只股票 |

| 字段 | 说明 |

## 4. 龙虎榜 · `lhb/`

三类数据，各有「历史合并 base」+「当日分片」：

| 类型 | base 文件 | 日分片 | 来源 sheet |
|---|---|---|---|
| 主力情报（自研加工） | `lhb_base_main.jsonl` | `{日}.lhb_main.jsonl` | 主力情报 |
| 总榜（东财） | `lhb_base_total.jsonl` | `{日}.lhb_total.jsonl` | 原始数据_总榜 |
| 席位明细（东财） | `lhb_base_seat.jsonl` | `{日}.lhb_seat.jsonl` | 原始数据_席位明细 |

说明：
- base 约覆盖近 90 个交易日的历史合并，**不导出**主观列「主力强度」「次日溢价预测」。
- 日分片在每日龙虎榜分析导出后写入；字段以当日 Excel 表头为准（主力情报列名可能与早期 base 略有差异，见下）。
- 用法建议：历史回看读 `lhb_base_*`；日更增量读当日 `{YYYYMMDD}.lhb_*`。

### 4.1 主力情报 · main

## 5. 个股主力净流入 · `main_flow/`

| 项 | 说明 |
|---|---|
| 文件 | `{YYYYMMDD}.main_flow.jsonl`（**仅日分片，无大合并文件**） |
| 粒度 | 一行 = 一只股票当日资金流 |
| 规模 | 全日约 5200+ 行（全 A） |
| 门槛 | 只导出「基本全市场」日（行数 ≥ 4000）；早期「净流入≥约3000万」截断 CSV **不导出** |
| 当前区间（示例） | 约 `20260717` 起 |

金额类字段多为东财展示字符串（如 `4.60亿`、`-5182.40万`），占比多为百分比字符串；另有数值字段 `净流入占流通%`。

| 序号 | 代码 | 名称 | 最新价 | 今日涨跌幅 | 今日主力净流入-净额 | 流通市值 | 净流入占流通% | 今日主力净流入-净占比 |
|---:|---|---|---:|---|---|---|---:|---|
| 1 | 002165 | 红 宝 丽 | 8.37 | 9.99% | 4.60亿 | 60.91亿 | 7.5472 | 46.82% |

另含：超大单 / 大单 / 中单 / 小单的净额与净占比。

## 7. 怎么读这些文件

1. **按日切片**：文件名 `{YYYYMMDD}.*` 即该交易日；合并类文件用行内 `trade_date` / `trade_date_ymd` 过滤。  
2. **JSONL**：逐行 `json.loads`；不要当整文件 JSON 解析。  
3. **空值**：缺榜、未复权溢价等可能为 `null`。  
4. **编码**：UTF-8。  
5. **离线包**：解压后目录结构即上表 `cos/`；连接器日更同步同一路径前缀。
