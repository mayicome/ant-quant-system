# 回归策略规格 v1.1（短线 · 反转 · 暴露×溢价框架）

> 依据《Quantitative Equity Portfolio Management》（Chincarini & Kim）的线性因子模型与 Fama-MacBeth 两阶段估计方法设计。
> 与《趋势策略规格 v1.2》同框架；**执行/账本/过滤底座对齐**，因子方向相反，**FM 左侧收益改用周一开盘→下周一开盘（B 口径）**。
> 状态：**设计已收敛，可作实现合同**；待接入数据验证。
> 相对 v1（豆包稿）：锁定 B 口径收益、决策溢价 ≤ w−2（滞后两期下标）、暴露方案 1、换手强制替换、跌停双口径、止损后复权、v1 验收硬门槛。

## 0. 策略定位

| 项 | 内容 |
|---|---|
| 策略类型 | 均值回归（反转），纯做多超跌反弹 |
| 理论框架 | 收益 = 因子暴露 × 因子溢价；每期横截面回归估计溢价 |
| 因子范围 | 仅技术因子（不考虑基本面因子、市场因子） |
| 暴露口径 | 当期可观测技术因子值（标准化后）充当暴露 |
| 核心逻辑 | A 股散户占比高、恐慌抛售频繁 → 短期超跌过度反应 → 均值回归 |
| 信号频率 | **因子日频计算**；**周五（周末日）快照、周调仓、周频 FM** |
| 默认市场 | A 股全市场（沪深主板 + 创业板 + 科创板，剔除北交所） |

**与趋势策略的关系**：同框架、同数据目录、同执行/递延/账本方案 A；独立运行、独立验证；两套通过后再评估合并。  
**刻意分歧（已拍板）**：趋势 FM 左侧为「周末日收盘→下周末日收盘」；本策略为「执行开盘→下一执行开盘」（B 口径）。对照 IC 时须注明收益窗口不同。

## 1. 市场范围、候选池过滤与数据

**候选池**：全市场 = 沪深主板 + 创业板 + 科创板（剔除北交所）。理由与趋势策略相同。

**候选池硬过滤（逐期执行，用时点快照防幸存者偏差）：**

| 过滤项 | 规则 | 原因 |
|---|---|---|
| ST/*ST | 剔除（按当时名称/状态） | 退市风险 + 涨跌幅规则不同 |
| 次新股 | 上市不足 120 个交易日剔除 | 因子数据不足 + 波动异常 |
| 流动性 | 过去 20 个交易日日均成交额 > 1 亿（含当日；参数可调） | 短线可交易性 |
| 停牌 | 剔除 | 无法交易 |
| 涨跌停 | **非事前过滤**；成交时用不复权开盘价判断能否成交 | 见 §5.3 |
| 连续跌停 | 过去 5 日**收盘封死跌停** ≥ 2 次剔除 | 反转特有：接刀高危区 |

**跌停 / 涨停双口径（硬约束）：**

| 用途 | 口径 | 语义 |
|---|---|---|
| 递延（买不进 / 卖不出） | **开盘价 = 涨/跌停价**（容差 0.005） | 成交模拟：开盘能否按模型成交 |
| 连续跌停过滤 | **收盘价 = 跌停价**（容差 0.005） | 风险识别：弱势是否极致 |

- 涨跌停价：用**除权参考价**计算（非简单前收），与趋势策略同一套 `limit_ratio` 逻辑。
- 盘中触及跌停但收盘未封死 → **不计入**连续跌停次数。
- 开盘封死即递延；v1 **不做**盘中开板可成交的盘中模型。

**数据目录（仓库已有）：**

| 用途 | 路径 |
|---|---|
| 后复权日线 | `data/daily_full_hfq` + `data/daily_cache_hfq`（`adjust=hfq`） |
| 不复权日线 | `data/daily_full` + `data/daily_cache`（`adjust=none`） |
| 读写入口 | `utils/daily_cache_reader.py` / `utils/daily_adjust_paths.py` |
| 上市日 | `data/all_a_stocks.csv` |
| 涨跌停幅度 | `utils/limit_ratio.py` |
| 基准 | `data/index_cache/000985.SH.csv`（中证全指）；超额另可对中证500 |

**字段：**

- 必需：后复权 OHLC（因子、FM 左侧开盘收益、止损）；成交额；不复权开盘/收盘（成交、涨跌停）；上市日期。
- 建议：复权因子/除权记录、停牌标记、时点上市退市快照。

覆盖长度：至少 4 年（W=52 周 + 样本外）。

## 2. 因子体系与暴露算法（5 因子）

所有因子在 **t 日收盘后**计算（后复权价口径），严格无前视。周决策日用当日收盘后截面。

**角色**：超跌主因子 + 企稳确认因子。

| # | 因子 | 公式（t 日口径） | 角色 | 理论方向 | 暴露 |
|---|---|---|---|---|---|
| 1 | REV5 短期反转 | `P(t)/P(t-5) − 1` | 超跌主 | − | winsorize → 截面 z-score |
| 2 | RSI14 | Wilder：`100×AU/(AU+AD)`，14 日 | 超跌主 | − | 同上 |
| 3 | BIAS20 | `(P(t) − MA20)/MA20` | 超跌主 | − | 同上 |
| 4 | VSHRK 波动收缩 | `ATR10/ATR20 − 1`（TR 需高低价） | 企稳确认 | − | 同上 |
| 5 | VDRAIN 量能枯竭 | `Vol5/Vol20 − 1`（成交额） | 企稳确认 | − | 同上 |

**日窗口 + 周持有（刻意保留，不周化因子）：**  
因子窗口描述**状态形成期**，持有期描述**状态有效期**，二者独立。与趋势策略日窗口口径一致，便于「趋势强则反转弱」对照。若实证 IC 半衰期 < 1 周 → **缩短持有期**，不周化因子。

**暴露算法（方案 1，已定）：**

1. 截面 winsorize：**对称 1%/99% 分位**（默认；不用 ±3σ）。
2. 截面 z-score → 暴露 `β`。**不乘 −1**；负向因子预期估出**负溢价**。
3. 在 OLS + 对称截尾下，对负向列先乘 −1 再回归与方案 1 **预测排序等价**；选方案 1 是为保留溢价符号诊断、少一层变换。

**共线性**：REV5/RSI14/BIAS20 预期高相关；见 §6 裁决规则。

## 3. 因子暴露计算（操作步骤）

1. t 日收盘后，对候选池算 5 因子原始值。
2. 缺失（停牌、历史不足、成交额缺失）→ 剔除出当期池。
3. 各因子截面 winsorize 1%/99%。
4. 截面 z-score → `β[t]`（行=股票，列=5 因子）。
5. 供当期回归（事后配对）与当期预测（用滞后滚动溢价）。

## 4. 因子溢价推算（Fama-MacBeth）

### 4.1 时间轴与 B 口径左侧收益（已定）

| 概念 | 定义 |
|---|---|
| 周边界 | 自然周；决策日 = 该周**最后一个交易日**（周五休市则当周末日） |
| 记周序 `w` | 第 `w` 个周决策日（收盘后） |
| 因子 / 暴露 | `β(w)` = `w` 日收盘后截面 |
| 执行开盘 | `OpenExec(w)` = 决策日 `w` 的**下一交易日**开盘（通常下周一） |

**持仓与收益窗口（B）：**

| 时点 | 事件 |
|---|---|
| 周 `w` 决策日收盘 | 因子 `β(w)`，生成目标；用**已实现**滚动溢价预测 |
| `OpenExec(w)` | 开盘调仓；本持仓窗口开始 |
| 周 `w+1` 决策日收盘 | 下一次决策 |
| `OpenExec(w+1)` | 周 `w` 决策对应持仓窗口结束 |

配对「暴露 `β(w)` → 随后一周持有收益」：

```
r(i, w) = P_hfq_open( OpenExec(w+1) ) / P_hfq_open( OpenExec(w) ) − 1
```

- 全程**后复权开盘价**；每期截面对 `r` 再 winsorize 1%/99% 后回归。
- `f(k,w)` 在 `OpenExec(w+1)` 开盘价可观测之后才实现（实现以该日开盘价入账）。

**决策日 `w` 收盘时，哪些 `f` 已实现（例：`D_w` = 2026-09-04 周五）：**

| 溢价 | 收益窗口终点 | 09-04 收盘时 |
|---|---|---|
| `f(w)` | `OpenExec(w+1)`（例：09-14 周一开盘） | 未发生 |
| `f(w−1)` | `OpenExec(w)`（例：09-07 周一开盘） | **未发生** ❌ |
| `f(w−2)` | `OpenExec(w−1)`（例：08-31 周一开盘） | **已发生** ✓ |

硬结论：决策日 `D_w` 最新可用 **`f(w−2)`**（在 `w` = 决策日下标约定下，**不是** `≤ w−1`）。

**明确不做**：周一开盘后用当日开盘价补算 `f(w−1)` 再生成订单——会使决策依赖执行日开盘价、订单与成交时序纠缠；v1 维持「周五收盘决策 → 周一开盘执行」。滞后两期是 B 口径固有代价；`f̄` 为 W 期均值，多滞一周影响很小。

### 4.2 每期横截面回归

```
r(i, w) = α(w) + Σ_k β(i,k,w) · f(k,w) + ε(i,w)
```

样本 = §1 过滤后的候选池（含连续跌停过滤）。

### 4.3 两种统计量必须分开（硬约束）

| 用途 | 公式 | 可否进回测/实盘预测 |
|---|---|---|
| **验证（事后）** | 全样本 `f̄(k)`、Newey-West t | **否** — 只出报告 |
| **决策（事前）** | 滞后滚动均值，见下 | **是** — 唯一允许 |

### 4.4 决策用滚动溢价（≤ w−2，无前视）

在决策日 `w`（收盘后）预测下一持仓期时，索引截断硬约束：

```
f̄(k, w) = mean{ f(k, w−2), f(k, w−3), …, f(k, w−W−1) }   # 共 W 期；最新 = w−2，最旧 = w−W−1
ᾱ(w)     = mean{ α(w−2), …, α(w−W−1) }                   # 截距同样滚动
```

- **禁止**用 `f(w)`、`f(w−1)` 做决策均值（在 `w` = 决策日下标时，`≤ w−1` 写法是错的）。
- 口头「第 w+1 周周五用到 `f(w−1)`」≡ 决策周下标 −2，与上式一致；勿把「滞后一期」写成 `≤ w−1`。

默认 **W = 52**（周调仓期数）。v1：**固定 52 起步**；52/78/104 扫描只作敏感性参考，不作全样本挑参后回填。

**预测与排序：**

```
E[r(i,w)] = Σ_k β(i,k,w) · f̄(k,w)     # 默认丢掉 ᾱ（横截面排序不变）；ᾱ 仍须滚动计算备查
```

降序取前 N。

**实现允许**：预计算全部 `f(k,w)`；回测循环决策时**只读下标 ≤ w−2 的溢价**做均值。

### 4.5 与趋势规格索引差异（对照）

| 项 | 趋势 v1.2 | 本策略 v1.1 |
|---|---|---|
| 左侧 `r` | 周末日收盘 → 下周末日收盘 | `OpenExec(w)` → `OpenExec(w+1)`（后复权开盘） |
| 决策日最新 `f` | `f(T−1)` | `f(w−2)` |
| 窗口 W | 52 周 | 52 周（同） |

## 5. 组合构建、回测与交易

### 5.1 价口径分离（对齐趋势方案 A）

| 用途 | 口径 |
|---|---|
| 因子、FM 左侧 `r`、IC/分组、**止损判断** | **后复权** |
| 买入/卖出成交、涨跌停/递延判断 | **不复权**开盘 |
| 组合账本（持仓股数、现金、NAV、换手、成本） | **全程不复权**（开盘成交 + 不复权收盘盯市） |

止损用后复权涨跌幅；账本用方案 A。二者分离，不做成交价↔后复权映射。

### 5.2 回测引擎（按周）

1. **决策日收盘**：更新数据 → 过滤 → 5 因子 → winsorize + z-score → 用 `f̄(·,w)`（≤ w−2）预测 → 排序 → 换手帽约束后得到目标组合。
2. **下一交易日开盘**：调仓（不复权开盘价）。
3. **成交判定**：开盘价触及涨/跌停价（容差 0.005）→ 递延规则。
4. **每日**：不复权收盘盯市；**止损**用后复权检查；现金收益 0。
5. **成本**：双边 0.15% 起点；扫描 0.10 / 0.15 / 0.20。

### 5.3 递延（与趋势同构；判定用开盘封死）

- **买入失败**（开盘价=涨停价）→ 槽位现金滞留，不重摊；下一决策日若仍在目标则再试；**最多顺延 1 个周调仓期**，否则放弃。
- **卖出失败**（开盘价=跌停价）→ 继续持有并如实计盈亏；下一决策日优先卖；最多优先顺延 1 期；期满仍卖不出则继续持有直到可卖。
- 若下一期仍在目标持仓 → 取消递延卖出。
- 报告：买入失败率、卖出失败率、平均递延期数。
- 遵守 A 股 T+1。

### 5.4 单期换手上限 30%（强制，按排名替换）

- **口径**：卖出/替换金额占 NAV；**闲置现金建仓不计入换手帽**（与趋势一致）。
- **强制执行**，不是监控指标。
- **算法**：
  1. 无约束目标 = `E[r]` 降序前 N（等权）。
  2. 若由当前持仓调到无约束目标的「替换腿」换手 ≤ 30% → 直接采用。
  3. 若超限：在「拟卖出」集合中保留 `E[r]` **较高**者（少卖），在「拟买入」集合中只纳入 `E[r]` **较高**者（少买），按排名贪心替换，直到替换腿换手 ≤ 30% 或无法再替换。
  4. 递延卖出占用的权重如实偏离，**不**为凑换手而偷调。

### 5.5 止损（回归特有，v1 启用）

- **触发**：单票后复权价格相对**后复权持仓加权均价（摊薄成本）**回撤 ≤ **−8%**（按决策用收盘后复权价检查）。
- **执行**：次日开盘不复权卖出；若开盘跌停卖不出 → 顺延至可卖，顺延期间**不追损**（不因继续下跌修改止损价）。
- 止损后若仍在候选且信号仍在，下一调仓日允许再买。
- 敏感性：−6% / −8% / −10%。

### 5.6 权重与容量

- 等权 1/N；递延/止损导致偏离允许 ±50%，超出不追平。
- 单票持仓市值 ≤ 该股 20 日日均成交额的 2%（可选实盘层）。
- 行业暴露上限可选，v1 可不启用。

## 6. 验证框架

| # | 检验 | 方法与判据 |
|---|---|---|
| 1 | 单因子 IC | 因子 vs 下期 **B 口径周收益** Spearman；反转因子 IC 为负正常，强度看**绝对值**；报 IC 均值、ICIR |

**滚动样本外**：与回测同一套 `f̄(k,w)`（≤ w−2），禁止验证用滚动、回测用全样本。

## 7. v1 验收门槛（样本外、扣成本后）

**硬门槛（全部满足才算通过）：**

| 层级 | 指标 | 门槛 |
|---|---|---|
| 因子 | 主力因子 ICIR | ≥ 0.3（反转按绝对值口径定义 ICIR） |
| 因子 | 主力因子 \|IC\| 均值 | ≥ 0.03 |
| 因子 | 主力因子溢价 \|t\| | ≥ 2（辅助 ≥ 1.5 可接受） |
| 因子 | 分组：前 3 vs 后 3 价差 t | ≥ 2 |
| 策略 | 样本外年化（净） | ≥ 15% |
| 策略 | 最大回撤（净） | ≤ 15% |
| 策略 | 夏普（净） | ≥ 1.0 |
| 策略 | 相对中证500 年化超额 | ≥ 8%（或 IR ≥ 0.5） |
| 交易 | 买/卖失败率 | ≤ 10% |
| 交易 | 平均递延期数 | ≤ 1.5 |
| 稳健 | W / N / 成本三档年化波动 | ≤ ±3pp |
| 稳健 | 样本外切两段 | **两段均为正收益** |

**主力因子**：定版后保留的超跌因子（预期为 REV5/RSI14/BIAS20 中经 VIF+IC 裁决留下的 2 个）。企稳确认为辅助。

**观察指标（不达不 fail，预警）：**

- 成本占比 ≤ 年化毛收益的 40%
- 主力溢价符号与理论方向一致（负向因子出正溢价 = 失效预警）
- 换手率是否长期顶满 30%（信号漂移预警）

**纪律**：门槛一经设定，**不得为通过而改门槛**；不合格回因子层迭代。

**样本外口径**：每期决策溢价仅用当时可得数据 → 全回测段均为滚动外推。自由度只在参数选择；v1 要求参数全样本选定后固定，检验段不再调。

## 8. 实盘方案

| 时间 | 动作 |
|---|---|
| 决策日 15:00 后 | 数据更新 → 因子 → 滞后滚动溢价 → 目标持仓（含换手帽） |
| 决策日盘后 | 可选人工复核 |
| 下一交易日 9:15~9:25 | 开盘价逻辑下单（集合竞价/开盘市价） |
| 该日盘后 | 核对成交、登记递延 |
| 每日 15:00 后 | 后复权止损检查；次日开盘执行 |
| 每日 | 跌停/停牌监控 |

订单金额 = 目标权重 × 总资产；100 股取整。

**与趋势合并（两套均通过后）**：先独立跑满一季；收益相关 &lt; 0.3 → 50/50；相关高 → 留 IC 更强者；合并前不改各自内部规则。
