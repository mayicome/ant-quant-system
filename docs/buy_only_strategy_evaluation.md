# 仅买入策略如何评价

策略如果只负责**选股与买入**、不包含卖出规则，无法产生“平仓”记录，因此不能按“单笔盈亏”算传统胜率。可以从下面几类方式评价。

---

## 一、盯市收益与回撤（已有）

- **总收益率**：期末总资产（现金 + 持仓按**期末价**市值）相对初始资金的比例。  
  公式：`(期末总资产 - 初始资金) / 初始资金`  
  含义：若一直持有到回测结束日，按当日收盘价盯市的整体收益。
- **最大回撤**：回测期内权益曲线从高点到低点的最大跌幅。  
  含义：持有过程中经历过的最大“浮亏”程度。
- **年化收益**：由总收益和回测天数折算出的年化收益率。

这些指标对“只买不卖”仍然有效，因为持仓每天都在按收盘价盯市。

---

## 二、持仓胜率与平均浮盈率（针对仅买入）

在**回测结束日**仍持有的仓位可以单独统计：

- **持仓胜率**：当前价 > 成本价的仓位数量 / 总持仓数量。  
  即：仍持有的标的中，有多少比例是浮盈的。
- **平均持仓浮盈率**：对每个持仓算 `(当前价 - 成本价) / 成本价`，再求平均。  
  即：仍持有的仓位平均浮盈百分比。

这样即使没有卖出记录，也能看出“当前这批买入”的质量。

---

## 三、若需“单笔收益”式评价（可选扩展）

若希望得到类似“每笔买入持有 N 天后的收益”：

- 在回测中约定**统一持有期**（如 N 个交易日），对每笔买入在 T+N 日按收盘价“虚拟平仓”，得到每笔的收益率。
- 再在这些虚拟平仓上算：胜率、平均收益、盈亏比等。

这需要回测引擎支持“固定持有期卖出”的模拟，可作为后续增强。

---

## 四、小结

| 指标           | 含义                         | 仅买入策略是否适用 |
|----------------|------------------------------|--------------------|
| 总收益率       | 期末盯市收益                 | ✅ 适用             |
| 最大回撤       | 持有期间最大回撤             | ✅ 适用             |
| 持仓胜率       | 期末仍持仓中浮盈比例         | ✅ 适用（已支持）   |
| 平均持仓浮盈率 | 期末仍持仓的平均浮盈百分比   | ✅ 适用（已支持）   |
| 成交笔数       | 买入次数                     | ✅ 适用             |
| 单笔胜率/盈亏比| 基于平仓的统计               | ❌ 无卖出时需用上面方式 |

当前回测在“仅买入”场景下会输出：总收益、回撤、成交笔数、**持仓胜率**、**平均持仓浮盈率**，便于评价选股与买入质量。
