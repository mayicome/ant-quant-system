| 项 | 内容 |

| 默认市场 | A 股全市场（沪深主板 + 创业板 + 科创板，剔除北交所），含 T+1、涨跌停、成本约束 |

## 1. 市场范围与候选池过滤

**候选池**：全市场 = 沪深主板 + 创业板 + 科创板（**剔除北交所**）。

选全市场而非指数成分的理由：
1. **横截面回归需要大样本**——全市场 4000~5000 只 vs 沪深300 的 300 只，溢价估计稳定性依赖样本量；
2. **趋势效应在中小盘更强**——大盘蓝筹机构定价充分、动量偏弱；中小盘趋势延续性更好；
3. **流动性用过滤解决，不靠换池子**——保住样本的同时控制可交易性。

**候选池硬过滤（逐期执行，用时点快照防幸存者偏差）：**

| 过滤项 | 规则 | 原因 |
|---|---|---|
| ST/*ST | 剔除（按**当时名称/状态**时点判断） | 退市风险 + 涨跌幅规则不同 |
| 次新股 | 上市不足 120 个交易日剔除 | 因子数据不足 + 波动异常 |
| 流动性 | 过去 20 个交易日日均成交额 > 1 亿（参数可调；**含当日**） | 短线可交易性 |
| 停牌 | 剔除（无官方停牌日历时：成交额/量为 0 且价格不变等启发式） | 无法交易 |
| 涨跌停 | **非事前过滤**；组合构建/成交时用不复权价判断一字板不可成交 | 见 §6 |

**数据字段清单（日频）：**

必需：
- **后复权收盘价**（因子计算、FM 左侧收益）
- **日成交额**（VPC5；库内单位按元，阈值 1 亿 = `1e8`）
- **不复权开盘价 / 收盘价**（成交执行、涨跌停判断）
- **上市日期**（次新过滤）

建议补充：
- 复权因子 / 除权除息记录（可选；方案 A 下账本不依赖复权因子）
- 涨跌停标记、停牌标记、时点上市/退市快照

不需要：最高/最低价（BRK20 用过去最高**收盘价**）。

覆盖长度：至少 4 年（估计窗口 52 周 + 样本外）。

## 2. 因子体系（5 因子 + 1 质量过滤）

所有因子在 **t 日收盘后**计算，严格无前视偏差。  
周调仓日使用**当日收盘后**算出的因子截面做排序与（如需要）当期横截面回归。

| # | 因子 | 公式（t 日口径） | 方向 | 暴露算法 |
|---|---|---|---|---|
| 1 | MOM20 中期动量 | `(P(t-1) / P(t-21)) − 1`，剔除最近 1 日 | + | winsorize → 截面 z-score |
| 2 | SLOPE60 趋势斜率 | 60 日 `ln(P)` 对时间序号 OLS 斜率 `b × 252` | + | 同上 |
| 3 | BRK20 突破强度 | `(P(t) − H20) / H20`，`H20 = max(P[t-20 … t-1])`（**不含当日**） | + | 同上 |
| 4 | VPC5 量价配合 | `R5 × (Vol5 / Vol20)`，成交额口径；`R5` = 近 5 日收益，`Vol5`/`Vol20` = 近 5/20 日成交额均值 | + | 同上 |
| 5 | MAALG 均线排列 | `(MA5 − MA10)/MA10 + (MA10 − MA20)/MA20` | + | 同上 |

价格 `P` 一律为**后复权收盘价**。窗口按**交易日**计数；中间停牌导致的缺口：该票在因子所需最短历史上不足则剔除出当期池。

**设计要点：**
- MOM20 剔除最近 1 日，减轻与短期反转混杂。
- SLOPE60 用对数价格回归，横截面更可比。
- VPC5 用成交额而非股数，规避股本变动。
- 标准化顺序：**先 R² 质量过滤（§3）→ 再对保留样本 winsorize（1%/99%）→ 再截面 z-score**。

---

## 3. R² 质量过滤（硬门槛）

- **位置**：因子计算之后、标准化之前。
- **规则**：SLOPE60 回归的拟合优度 R² 低于阈值 → 该票当期出局（不参与标准化、不参与溢价回归、不进入候选排序）。
- **默认阈值**：全市场 R² 中位数作起点；回测扫描 `0.4 / 0.5 / 0.6 / 0.7`。
- **联动**：过滤后样本过小（如仅几十只）时放宽阈值，保证溢价回归样本量。

## 4. 因子溢价估计（Fama-MacBeth 两阶段）

### 4.1 时间轴（周频）

| 概念 | 定义 |
|---|---|
| 周边界 | 自然周；调仓观测日 = **该周最后一个交易日**（周五休市则用当周末日） |
| 记 `T` | 第 `T` 个周调仓观测日（收盘后） |
| 因子 / 暴露 | 每日可算；决策只用 `T` 日收盘后因子 |
| 执行 | **`T` 的下一交易日开盘**（不复权开盘价） |
| FM 左侧收益 | 后复权周收益（见下） |

### 4.2 左侧收益（研究 / 回归用）

```
r(i, T+1) = P_hfq(T+1) / P_hfq(T) − 1
```

- `P_hfq`：后复权收盘价。
- 周频：`T+1` / `T` 均为各自周的**最后一个交易日收盘**（「周五收 / 上周五收」口径，遇休市用当周末日）。
- **每期横截面对 `r` 做 winsorize 1%/99%** 后再回归（防除权异常、坏数据、复牌跳空污染）。`±3σ` 仅作敏感性，默认不双轨。

### 4.3 第一步 —— 每期横截面回归

```
r(i, T+1) = α(T) + Σ_k β(i,k,T) · f(k,T) + ε(i,T)
```

- `β(i,k,T)`：股票 i 在 `T` 日的标准化因子暴露（已知）。
- `f(k,T)`：因子 k 在 `T` 期的溢价（待估）。
- 回归样本 = 通过 R² 过滤且通过硬过滤的可交易池。

### 4.4 第二步 —— 滚动溢价与预测

- 估计窗口 **W = 52**（单位 = **周调仓期数**，非日历日）。
- 在 `T` 日做预测时，仅使用**已实现**的历史溢价 `{f(k, T-W) … f(k, T-1)}`（严格无前视；不含当期未实现的 `f(k,T)`，因 `r(T+1)` 尚未发生）。
- `f̄(k,T) = mean( f(k, τ) )`，τ ∈ [T−W, T−1]。
- `ᾱ(T)` 同理滚动；**选股排序可丢掉截距**，只用 `Σ_k β(i,k,T) · f̄(k,T)`（默认丢掉 α，保持横截面可比）。
- 预测：`E[r(i,T+1)] = Σ_k β(i,k,T) · f̄(k,T)`，降序取前 N。

显著性报告（研究用）：

```
f̄(k) = mean_τ f(k,τ)
t(k)  = f̄(k) / (σ(k) / √T_obs)   ← 短线用 Newey-West 修正
```

## 5. 验证框架

| # | 检验 | 方法与判据 |
|---|---|---|
| 1 | 单因子 IC | 因子值与下期周收益的 Spearman；IC 均值、ICIR |
| 2 | 预测分组单调性 | 预测值 10 组，组间均收益单调；多空价差显著 |
| 3 | 回归解释力 | 每期横截面回归平均 R² |
| 4 | 溢价显著性 | `\|t\| ≥ 2` 为强信号 |
| 5 | 共线性 | 相关矩阵 + VIF；v1 **只诊断、不自动正交**；严重则保留 IC 更高者 |
| 6 | 稳健性 | 滚动样本外、窗口 / R² / 成本敏感性 |

**砍因子**：仅在研究定版阶段一次性处理；定版后回测/实盘因子集固定，不动态砍。

## 6. 组合构建与交易

### 6.1 基本规则

| 项 | 规则 |
|---|---|
| 选股 | `E[r]` 降序取前 **N = 20** |
| 权重 | **等权**；验证通过前不做暴露加权 |
| 行业/市值中性 | 先不做 |
| 止损/止盈 | 先不做；纯再平衡 |
| 单期换手上限 | **30%**（按卖出/替换金额占 NAV；**闲置现金建仓不计入换手帽**，否则空仓无法加满） |
| 成本 | 双边 **0.15%** 起点（佣金+印花税+滑点打包；实现时可拆：印花税仅卖出） |
| 基准 | 中证全指（000985），仅作超额对比 |
| 执行 | 调仓观测日 `T` 收盘决策 → **下一交易日开盘**成交 |

### 6.2 价口径分离（方案 A，已拍板）

| 用途 | 价格口径 |
|---|---|
| 因子、FM 左侧 `r`、IC / 分组研究 | **后复权收盘** |
| 买入/卖出成交、涨跌停/一字板判断 | **不复权**开盘/收盘 |
| 组合账本（持仓、现金、NAV、换手、成本） | **全程不复权**：开盘成交 + 不复权收盘盯市 |

研究序列与交易账本分离，**不做**成交价 ↔ 后复权空间的映射。

### 6.3 买不进（涨停一字板，不复权判断）

1. 当期买入失败 → **该目标槽位现金滞留**（如实计 0 收益），订单标记 `"递延买入"`。
2. **不把失败权重重摊到其他已持/待买股票**（避免隐形加仓）。
3. **下一调仓日优先处理**：若该股票**仍在当期目标组合**，按当日开盘价再试买入。
4. 若已不在目标组合 → **自动放弃**，不追买。
5. **最多顺延 1 个周调仓期**；连续两个调仓日都买不进 → 强制放弃。

### 6.4 卖不出（跌停一字板，不复权判断）

1. 当期卖出失败 → **继续持有**，后续盈亏如实计入组合，标记 `"递延卖出"`。
2. 下一调仓日**优先开盘卖出**；仍跌停则再顺延。
3. **最多作为「优先卖出」顺延 1 期**；顺延期间占用的权重是组合真实偏离，**不得偷偷调平**。
4. 若下一期该股**仍在目标持仓** → **取消递延卖出**，恢复正常持有。
5. 优先顺延期满仍卖不出 → **继续持有直到可卖**（回测如实记录），不再享受优先队列以外的特殊待遇。

### 6.5 T+1

A 股 T+1：当日买入不得当日卖出；再平衡引擎须遵守（含递延成交后的可卖日）。
